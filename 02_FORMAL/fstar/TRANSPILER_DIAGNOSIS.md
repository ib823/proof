# F* Transpiler Diagnosis

**Date:** 2026-02-12
**Worker:** C (F* Crypto Proofs)
**Issue:** F* corpus has placeholder stubs instead of real implementations

---

## Problem Statement

All 244 F* files were auto-generated by `scripts/generate-full-stack.py`, but the transpiler **ignores Coq definition bodies** and replaces them with type-appropriate placeholder values.

### Example

**Coq (Syntax.v lines 42-50):**
```coq
Definition sec_level_num (l : security_level) : nat :=
  match l with
  | LPublic   => 0
  | LInternal => 1
  | LSession  => 2
  | LUser     => 3
  | LSystem   => 4
  | LSecret   => 5
  end.
```

**Generated F* (Syntax.fst line 201) — CURRENT:**
```fstar
let defn_sec_level_num (p_l: security_level) : Tot nat = 0
```

**Expected F* (what it SHOULD be):**
```fstar
let sec_level_num (l: security_level) : Tot nat =
  match l with
  | LPublic   -> 0
  | LInternal -> 1
  | LSession  -> 2
  | LUser     -> 3
  | LSystem   -> 4
  | LSecret   -> 5
```

## Root Cause Analysis

### Transpiler Code (`scripts/generate-full-stack.py` lines 374-393)

```python
# Definitions
for defn in parsed.definitions:
    pts = _extract_param_types(defn.params)
    params_str = '...'
    ret = _fstar_type(defn.ret_type, known_types)
    default = default_for_type(ret)  # <-- USES DEFAULT, NOT BODY
    safe_name = f'defn_{_sanitize_ident(defn.name, "defn").lower()}'

    lines.append(f'let {safe_name} {params_str} : Tot {ret} = {default}')
    #                                                          ^^^^^^^^
    #                                                          BUG: Should use translated body
```

**The problem:**
- Line 379: `default = default_for_type(ret)` computes a placeholder
- Line 384/390: Uses `{default}` instead of translating `defn.body`
- **`defn.body` is PARSED but NEVER USED**

### Placeholder Defaults (`_fstar_default_value`, lines 269-283)

```python
def _fstar_default_value(ret: str):
    if ret == 'bool':
        return 'true'
    if ret == 'nat':
        return '0'
    if ret == 'int':
        return '0'
    if ret == 'Type0':
        return 'unit'
    if ret == 'string':
        return '"riina"'
    if ret.startswith('list '):
        return '[]'
    return '0'  # Fallback
```

**Impact:**
- ALL Coq `match` expressions → placeholder defaults
- ALL Coq `if-then-else` → placeholder defaults
- ALL Coq function bodies → placeholder defaults
